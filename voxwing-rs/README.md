# 体素星翼 VOXWING（Bevy 0.20 原生版）

用方块拼战机，在小行星带里联机空战。服务器权威、客户端预测，走 QUIC（UDP）。

## 运行

需要 Rust 1.97+（Bevy 0.20 的最低要求）。第一次编译 Bevy 要几分钟。

```bash
cargo run -p voxwing-client --release
```

客户端自带服务器：在「出击 → 创建房间」里点出击，就会在本机 4433 端口开房间并加入，单人也能玩。

独立服务器（不需要显卡，适合放在云主机上）：

```bash
cargo run -p voxwing-server --release -- --mode ffa --bots 4
```

| 参数 | 说明 |
| --- | --- |
| `--port 4433` | UDP 端口 |
| `--bind 0.0.0.0` | 监听地址；`127.0.0.1` 只允许本机 |
| `--mode coop` | 合作波次（默认）：一起打一波波 AI，清完一波全员修复，阵亡的人下一波重生 |
| `--mode ffa` | 自由混战：玩家和 AI 互相攻击，阵亡 4 秒后重生 |
| `--bots N` | 自由混战时场上保持的 AI 数量（默认 4） |

## 部署到 Linux 服务器

现在有一台服务器在 `10.0.0.10:4433` 上运行（合作波次），在「加入房间」里填这个地址即可。它在 `logan` 用户的 tmux 会话 `voxwing` 里运行，日志在 `~/voxwing-server.log`，机器重启后需要重新启动。

改了代码后，一条命令同步源码、在服务器上编译并重启：

```bash
./deploy.sh                                   # 默认 logan@10.0.0.10，合作波次
./deploy.sh logan@10.0.0.10 --mode ffa --bots 6
```

服务器需要 C 编译器（`build-essential`）、用户目录里的 Rust（`~/.cargo`），防火墙放行 UDP 4433。

## 局域网 / 公网联机

1. 房主在「创建房间」开房，页面上会显示本机局域网地址，例如 `192.168.1.20:4433`。
2. 朋友在「加入房间」里填这个地址，点出击。
3. 连不上时检查：
   - 房主的防火墙放行了 **UDP** 4433；QUIC 不走 TCP。
   - macOS 第一次开房时会弹出「允许传入连接」，要点允许。
   - 公网联机需要路由器把 UDP 4433 转发到房主，或者直接用独立服务器。

连接 5 秒没有响应会自动放弃，回到出击准备并给出原因，可以直接重试。

驾驶舱、机翼和引擎是起飞必需的。右侧「起飞检查」会实时说明哪里不合格：结构是否连通、推重比、升力、重心是否落在机翼区域内、驾驶舱视野等。武器和其他部件可以随便摆。

共 20 种部件，分五类：

| 分类 | 部件 |
| --- | --- |
| 核心 | 驾驶舱、机翼、引擎 |
| 结构 | 船体、装甲、骨架（很轻，适合拉长机身）、灯块（按涂装颜色发光） |
| 机动 | 陀螺仪（放哪都一样）、尾翼（加强偏航，不产生升力）、小推进器（推力 10，用来补推力或调正推力中心）、姿态推进器（离重心越远越有力） |
| 武器 | 激光炮、机炮、等离子炮、导弹舱、轨道炮（一发连穿 3 个方块，很耗能）、霰弹炮（一次 7 发弹丸，射程短） |
| 系统 | 反应堆、护盾发生器、电容（能量上限 +90，不回复能量） |

方块摆在哪会影响飞行手感（都在 `shared/src/analysis.rs` 里算）。不强制对称，怎么叠都能起飞，只是飞起来会受影响：
- **转动惯量**：俯仰、偏航、翻滚各算各的转动惯量，转速取决于「转向力 ÷ 转动惯量」。重块离重心越远，绕那个轴转得越慢：装甲堆在翼尖翻滚变慢，机身拉长俯仰和偏航变慢。
- **转向力**：机翼离重心越远越有力，前后方向的距离影响俯仰和偏航，左右方向的距离影响翻滚。陀螺仪放在哪都提供同样的转向力，但它重，靠近重心放最划算。
- **推力偏心**：引擎的推力中心偏离重心超过 1/4 格，全速时机头会被拉偏，加速时更明显。战斗中被打掉一侧引擎，飞机会往坏掉的那一侧偏。
- **升力偏心**：每片机翼的升力一样。升力中心偏离重心超过 1/4 格，飞机会一直侧滚：机翼多的一侧被抬起来，重的一侧往下掉。侧滚最多占翻滚能力的 3/4，压杆总能救回来。战斗中掉了半边机翼也是这样。
- **持续火力**：激光和等离子炮耗能。武器总耗能超过反应堆回复时，满火力几秒后能量就会耗尽，之后只能按回复速度开火。机库会同时显示「火力」（爆发）和「持续」火力。

**菜单**：↑↓ 选择，Enter 确认，H 进机库，S 打开设置，Esc 返回或退出。

## 界面流程

```
主菜单 ──出击──▶ 出击准备 ──出击──▶ 正在连接 ──▶ 飞行
  │                │  ▲                 │          │
  │                │  └── 连接失败 / 断开（原因 + 重试）
  ├──机库◀─────────┘                               ├─ Esc：暂停（继续 / 设置 / 返回出击准备 / 退出）
  ├──设置（浮层，暂停菜单里也能打开）               ├─ Tab：记分板
  └──退出（有确认）                                 └─ 阵亡：谁击落了你 + 重生规则
```

**观战**：出击准备里的「观战」按钮（或按 V）不驾驶，附身到场上的飞机上看它打，机体没通过起飞检查也能用。
- 「创建房间」页观战时，会在本机开自由混战房，至少 2 架 AI 互相打；「加入房间」页观战时，看别人的房间。
- 镜头和自己开飞机时一样，跟在被观战的飞机后面，C 切到它的座舱视角。左下的船体剖面、护盾、速度、武器、雷达和左上的战绩，都换成这架飞机的。
- ← / →（或 A / D、左键）换一架，AI 排在前面。被观战的飞机被击落时，镜头先绕残骸转两秒，再切到击落它的那架。
- 观众不占记分板，也不算在合作模式的人数里。合作模式没人驾驶时不会开打。

设置、机体和最近加入的服务器保存在 `~/.voxwing/`。分享码（`VW1.` 开头）和网页版通用，但只限原有的 12 种部件；用了新部件的机体，网页版读不出那些方块。

**画面设置**：
- 显示模式：窗口 / 无边框全屏 / 独占全屏。
- 分辨率：窗口模式下只列出放得下的尺寸；独占全屏用显示器自己报告的分辨率，同一分辨率下自动取最高刷新率；无边框全屏跟随显示器。
- 垂直同步。
- 帧率上限：只提供显示器刷新率的整数分之一，比如 120 Hz 显示器上是 120 / 60 / 40 / 30。关掉垂直同步时，另外还能选高于刷新率的上限。

帧率上限的实现在 `client/src/pacing.rs`。显示器只在固定的刷新节拍上换画面（120 Hz 是每 8.3 ms 一次）。如果限帧器按自己的时钟睡眠，就会和这个节拍错开，导致有的帧在屏幕上停一次刷新，有的停两三次，帧数看着很稳，画面却在抽。所以现在的做法是：
- 等待放在渲染线程上，在取交换链图像之前。macOS 上用 CoreVideo display link 拿到真实的 vblank 时刻，每帧都在「目标那次刷新的前一次刷新」刚过时开始渲染，这样有整整一次刷新的时间来渲染和提交，计时抖动远小于这段余量，每帧都正好落在该落的那次刷新上。其他系统拿不到 vblank 相位，只按显示器刷新率的整数倍定时。
- 开着垂直同步时，等于或高于刷新率的上限直接交给垂直同步，不再额外等待。
- 游戏时间按整帧周期推进，而不是用「这帧渲染完的时刻」（那个时刻是抖动的），所以画面运动和实际上屏的节奏完全一致。

`--frame-stats` 每 5 秒打印一次帧间隔、游戏时间步长，以及每帧在屏幕上停了几次刷新。

改显示模式或分辨率后有 15 秒确认：不点“保留”就自动还原，选到显示器不支持的模式也不会卡住。关掉设置等于保留。窗口太矮时设置项会滚动，“完成”按钮始终可见。

## 代码结构

```
crates/
  shared/       确定性模拟，不依赖 Bevy：方块与机体分析、飞行物理、武器、AI、协议
  net/          QUIC 端点（quinn + 自签证书）和带长度前缀的帧
  server/       权威服务器：60 Hz tick、合作/混战规则、延迟补偿；也可作为库嵌入客户端
  client-core/  联机客户端核心，不依赖 Bevy：预测、和解、插值、时间同步
  client/       Bevy 客户端
    ui/         自己的组件库（见下）
    screens/    主菜单、出击准备、设置和机体选择浮层
    hangar.rs   机库
    flight/     飞行：HUD、特效、环境、飞船同步
```

### UI 组件库（`crates/client/src/ui`）

视觉语言是克制的舰桥显示屏：深色纯色面板、切角、1px 细线，不用渐变和发光；青色只用于小面积强调和主按钮，橙色只用于警报。布局有一套固定尺度（`ui/mod.rs`）：所有间距都是 4 的倍数，屏幕边距 24，面板内边距 20，区块之间 16、区块内 8，控件高度 36（主按钮 52）。所有面板、按钮、标签和分段式属性条都由一个 UI 着色器（`ui/plate.wesl`）绘制。

自带字体（都是 SIL Open Font License，许可证在 `crates/client/assets/fonts/`，编译时嵌入程序）：

| 字体 | 用途 |
| --- | --- |
| 得意黑 Smiley Sans | 只用于游戏标题和战斗播报（原版文件，未修改） |
| Chakra Petch | 数字、英文标签、HUD 读数。垂直度量（hhea/OS2 的 ascender/descender）改成和 Noto Sans SC 相同，两种字体并排时基线才对得齐 |
| Noto Sans SC | 正文和各级标题（可变字重：正文 500，标签 700，标题 800）；按游戏用字和 3755 个常用汉字做了子集。子集外的字（比如玩家起的名字）回退到系统中文字体 |

所有控件只发出一种消息 `UiAction`，由各界面的普通系统统一处理，所以键盘快捷键和鼠标点击走同一条路径。

| 组件 | 说明 |
| --- | --- |
| `spawn_btn` | 8 种样式：Primary、Accent、Normal、Ghost、Danger、Menu、Tile、Segment。悬停时左侧亮条展开，有音效和快捷键角标；支持 Tab 键焦点 |
| `spawn_panel` / `spawn_header` | 带四角标记的面板；带竖条和横线的小标题 |
| `spawn_toggle` / `spawn_slider` / `spawn_field` | 开关、滑块（带数值）、文本框，基于 `bevy::ui_widgets` 的无头控件 |
| `spawn_stat` | 属性条 |
| `ModalReq` | 确认框；Esc 等于取消 |
| `Toasts` | 底部提示条 |
| `Tip` | 悬停提示 |
| `Fade` | 切换界面时的淡入 |

## 联机实现

- **服务器权威**：60 Hz tick，每 2 tick 发一次快照（30 Hz）。快照和输入走 QUIC 不可靠数据报；加入、事件、计分走可靠流。
- **客户端预测**：本机飞船用和服务器同一份 `shared::flight` 代码先行模拟。收到快照后回滚到服务器状态，重放未确认的输入；误差不直接跳变，而是作为视觉偏移逐渐衰减。
- **时间同步**：客户端微调本地 tick 速度，让输入比服务器领先约 3 tick 到达。
- **远端飞船**：延迟 6 tick 做 Hermite 插值。
- **延迟补偿**：服务器保存最近的位置历史，判定命中时按射击者的视图延迟回溯。
- **方块破坏**：只同步「哪个方块被打掉」的事件。脱落判定（`ShipBody::settle`）是确定性的，各端各算各的，碎块物理只在本地模拟。

无头压测（3 个机器人客户端，单向延迟 50 ms）：每 450 次预测校验约 2–4 次和解修正，每个客户端约 8 KB/s，服务器 tick 平均 0.02 ms。

```bash
cargo run -p voxwing_client_core --example bots -- --clients 4 --secs 40 --latency 50 --mode ffa
cargo test -p voxwing_shared
cargo run -p voxwing_shared --example stats   # 各预设机型的数值，以及掉一台引擎后的变化，调平衡用
```

## 开发用参数（客户端）

| 参数 | 说明 |
| --- | --- |
| `--launch host\|join\|watch\|watch-join` | 启动后直接出击，或直接观战（watch 本机开房，watch-join 加入「加入房间」里的地址） |
| `--local` | 开房只监听 127.0.0.1（不会触发防火墙弹窗） |
| `--autopilot` | AI 代飞 |
| `--latency 毫秒` | 模拟单向延迟 |
| `--screen lobby\|join\|error\|hangar\|settings` | 从指定界面启动 |
| `--screenshot 路径 --after 秒 [--count N --every 秒] [--exit]` | 定时截图 |
| `--offscreen` | 渲染到离屏图像（大小取设置里的窗口尺寸）并隐藏窗口：屏幕锁定时也能截图，也不会弹窗打扰 |
| `--force pause\|board\|side\|tip\|revert:秒` | 到时间后强制显示暂停菜单、记分板、悬停提示、显示设置的还原倒计时，或切到飞船侧面的镜头（看尾气） |
